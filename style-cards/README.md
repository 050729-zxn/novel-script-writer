# 文风卡目录

这个目录存放**你自己喂文生成的文风卡**。蒸馏方法见 `../references/style-distillation.md`。

- 用 `_template.md` 作空模板:喂文后按 9 轴逐轴填「观察 / 规则 / 锚点原句」,存成 `<作者名>.md`。
- 之后说「用 XX 味儿写」,本 skill 直接调对应卡,不必重新蒸馏。
- 仓库**不预置任何具体作者的文风卡**:文风卡随喂随生成,既避免个例依赖,也让任何文风都能写出来。你自己的卡留在本地,不必提交。

## 一个最小示例(喂文 → 出卡 → 复用)

1. **喂文**:用户说「学鲁迅《孔乙己》的味儿写一段,这几段是原文:……」
2. **出卡**:按 `_template.md` 蒸馏成九轴,存 `style-cards/lu-xun.md`(每轴带 2–3 句锚点原句)。
3. **复用**:之后说「用鲁迅味儿写一段茶馆场景」,直接调 `lu-xun.md`,不必重新喂文。

> 喂文生成的卡含原文摘录,只在本地用、不要提交。仓库已用 `.gitignore` 忽略,并有 pre-commit 钩子防误提交(启用方法见根目录 README)。
