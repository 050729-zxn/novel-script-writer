# novel-script-writer

一个通用的文学写作 skill,适用于 Claude Code、Codex、Cursor 等任何能读 agent skills 的工具。写小说、网文、短篇、AI 短剧剧本——任何类型、任何文风、任何语言,把 AI 味洗掉,把文学手艺放回去。

## 为什么做这个

大模型写的文字,语法滴水不漏,风格却死气沉沉:同样的句长、同样的填充词、同样的「不是 X 而是 Y」、同样的三段式排比。让它模仿某个作者,你得到的是戏服,不是指纹。

这个 skill 治两个病:

1. **去 AI 味**——盯的是「结构层」的痕迹(句长匀、否定式平行、三段式、万能动作),不是换个新模型就过时的词表。
2. **学文风**——给一段真实文字,蒸馏成一张可复用的「文风卡」,让 AI 写得*像作者*,而不是*介绍作者*。

## 能做什么

- **按需输出**——设定 / 大纲 / 整本小说 / AI 短剧剧本,只要你要的,不多塞。
- **去 AI 味**——按语言删填充词、陈词动作、「不是 X 而是 Y」、强行三段、空泛升华。自带 `scripts/deai-check.py` 扫任何稿子,先标候选点再人工改。
- **文风蒸馏(喂文)**——喂几章,抽出九轴指纹 + 真实锚点句,再照着写、照着改。喂得越多越像「集大成」:什么文风都能现蒸现用。
- **长篇防失焦**——一张状态卡(人物 / 伏笔 / 时间线 / 世界规则 / 章末钩子),扛住五十章不自我矛盾。
- **多语言文学写作**——十种语言,各自有去 AI 味清单、文学规范、锚定在公版名著的正面笔法。
- **文生图 / 文生视频提示词**——把人物、场景、封面、短剧镜头转成绘图/视频 AI 能无歧义读懂的结构化提示词,适配即梦/Midjourney/可灵/SD/Runway/Sora。
- **Word 导出**——`scripts/novel2docx.py`,中文小说排版(首行缩进 2 字符、两端对齐、1.5 倍行距)。

## 安装

```bash
mkdir -p ~/.claude/skills
cp -r novel-script-writer ~/.claude/skills/
```

## 跨工具通用

这个 skill 是纯 Markdown(`SKILL.md` + `references/` + `scripts/`),不依赖 Claude 专属运行时。`name` / `description` 前置元数据用的是通用 agent-skills 约定,丢进任何按目录读 skills 的工具就能用:

| 工具 | skills 目录 |
|---|---|
| Claude Code | `~/.claude/skills/` |
| Codex CLI | `~/.agents/skills/`(或仓库里的 `.agents/skills/`) |
| Cursor / Antigravity | 各自的 skills 目录 |

两个脚本(`deai-check.py`、`novel2docx.py`)是纯 Python,任何环境都能跑。`SKILL.md` 里唯一的工具相关细节是结构化提问(Claude 用 AskUserQuestion,其它工具退化为编号列出)。

## 用法

```
写一个中式玄幻短篇,5000 字,第三人称,主角叫林风,先给大纲再写正文
```

```
模仿《龙族》的文笔写一段雨夜独白
```

```
写一个 3 分钟 AI 短剧剧本,每个镜头附通用视频提示词,对话用英文、旁白用中文
```

模仿文风的:先喂真实文字,skill 蒸馏成文风卡,再写。

## 文风蒸馏怎么工作

九轴:句长与标点、分段、用词、对话、视角、意象、情绪强度、节奏结构、禁区。三条规矩:

- **规则会骗人,原句不会。** 每个轴都要挂 2–3 句从样本里摘的原句。
- **三次成信号。** 出现一次是即兴,出现三次才是签名。
- **调料不是公式。** 签名动作是工具,不是清单;短篇用一两样,从不堆满。

空模板在 `style-cards/_template.md`,你自己的卡留在本地。仓库不预置任何具体作者的卡,想写谁的味儿就喂谁。
