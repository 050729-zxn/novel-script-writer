# 30 秒演示脚本(录屏用)

用于 README 的 GIF / 视频。三步,每步约 10 秒,三段硬切,别录打字过程。

## 画面与操作

**第 1 步(0–10s):喂文,出文风卡**
- 终端输入:`模仿金庸的文风,写一段雨夜独白`
- 画面:Claude 先蒸馏,闪现「文风卡」一角——九轴 + 锚点原句。
- 字幕:`不是介绍金庸,是写得像金庸`

**第 2 步(10–20s):出文**
- 画面:输出一段带金庸味的文字——旧白话虚词、长句串起动作、旁白议论腔。
- 字幕:`喂得越多,越像「集大成」`

**第 3 步(20–30s):量化去 AI 味**
- 终端跑:`python scripts/deai-check.py 正文.txt --lang zh`
- 画面:报告滚出来——填充词 0、万能动作 0、否定式平行 0、三段式 0。
- 字幕:`去 AI 味,可量化`

## 收尾

最后 2 秒定格在 deai-check 的「0 处」报告上,叠仓库地址:`github.com/050729-zxn/novel-script-writer`。

## 录制要点

- OBS / QuickTime 录终端窗口,输出 30 秒、16:9、≥1080p。
- 终端用大字号 + 深色主题,文字清楚。
- 字幕用简洁黑体白字,别加花哨转场。
