# 多语言排版规范

小说/剧本的排版与标点,跟着正文语言走。总原则:**每个文字系统有自己的一套规则,拿拉丁(英语)的习惯去排中文、阿拉伯语都会出错**——拉丁有 x 高度、大写高、基线这套轴,中文重心在方格中心,日文占一个方块,阿拉伯语靠连写、印度系文字挂在头线上,彼此不通用。下面按「通用 → 各文字系统 → 混排 → 导出」分。

## 一、通用(所有语言都遵守)

1. **标题层级统一**:书名用一级标题,章用二级,章内小节用三级;别跳级、别乱用,同一层级样式全篇一致。
2. **段落要短**(网文习惯一段 1–4 句);缩进与对齐按文字系统分,别一套规则套所有语言——拉丁文段间空行、不缩进;中文首行缩进两字、两端对齐(见各语言条目)。
3. **标点、引号跟随这句话的语言**:用哪种语言写,标点和引号就用哪种语言的(见下面各条目),别中英标点混用。
4. **数字与单位之间加空格**(拉丁、中文都适用):`5000 字`、`3 天`,不是 `5000字`。
5. **方向不乱**:阿拉伯语、希伯来语从右到左,别因为混入拉丁词就把整段方向写反。
6. **输出前自检排版**:标题层级对不对、段间有没有空行、标点引号跟语言一致不一致、RTL 段落方向对不对。排版错了,正文再好也显糙。

## 二、拉丁文字(英语、西班牙语、法语、德语、葡萄牙语…)

1. 句首大写;书名、刊物名、作品名用斜体(聊天里没斜体时可用引号或书名号替代,但全篇统一)。
2. **引号按语种分,别都用英文弯引号**:
   - 英语 / 葡萄牙语:`"…"`(外层),内层 `'…'`。
   - 德语:`„…"`(开头低九、结尾高六)。
   - 法语:`« … »`(引号与被引文字之间加不换行空格)。
   - 西班牙语:`« … »` 或 `"…"`,全篇二选一;疑问句、感叹句句首加倒标 `¿`、`¡`。
3. 段落之间空行,不首行缩进(除非导出纸质排版)。
4. 长单词换行按各语言规则,别硬断。

## 三、中文、日文

1. 用全角标点:`。` `,` `!` `?` `:` `;`,别用半角 `.` `,`。
2. 引号:`「…」`(外层)`『…』`(内层),或全角 `“…”`(外层)`‘…’`(内层),全篇统一。
3. 书名用书名号 `《》`,别用斜体。
4. **首行缩进两字 + 两端对齐 + 段间紧凑**:中文小说/网文(起点、番茄、晋江等主流平台)正文每段开头空两个全角字符,两端对齐,段间不空行,行距 1.5–2 倍。纯 Markdown/聊天渲染不出缩进和对齐,要真排版就落到 Word/PDF,在 Word 里设「首行缩进 2 字符、两端对齐、1.5 倍行距」。
5. 中英文、中文与数字之间加空格(如 `AI 短剧`、`5000 字`);纯中文句子内部不加空格。
6. 日文引号用 `「」`,长音、促音、拗音按日文书写,别和中文混。

## 四、阿拉伯语、希伯来语等 RTL(从右到左)

1. **整段从右到左**,标点落在右侧句末;别把句子内部顺序写反。
2. 阿拉伯语是连写文字,**不能拉开字距**(letterspacing 会把字母连接断开);没有斜体传统,**不用斜体、假加粗强调**——假加粗会把连写糊成一团,强调改用措辞或重复。
3. **数字在阿拉伯语里保持从左到右**嵌入(如 `123` 仍是 LTR),夹在阿语文字中间时由双向算法自动处理,不要手动重排字符。
4. 引号按阿拉伯语习惯(`«…»` 或 `“…”`),全篇统一。
5. **行距要比拉丁更宽**:阿语、希伯来语的上下标记和连写需要更多行高,套英文行距会把符号裁掉。
6. 希伯来语同理:从右到左,标点、数字规则同上。

## 五、混排与双向文本(一行里两种文字系统)

1. 一句话内**不混两种文字系统的标点**:中文句子里塞英文引号、阿语句子里用英文逗号,都是错。
2. 阿语/希伯来语句子里夹英文品牌名、代码、数字时,方向由 Unicode 双向算法自动处理,别自己把字符顺序颠倒写。
3. 中英文混排:`中文 English 中文` 之间加空格;标点跟随「这句话的主语言」。
4. 别为了秀多语言硬切,切换要符合叙事需要(见 SKILL.md 多语言规则)。

## 六、导出 Word / PDF 时的字体与行距

(只有在把正文落成 Word/PDF 时才需要,聊天里不用管字体。)

1. **一个字体很难同时盖住多种文字系统**;按脚本用对应字体:
   - 拉丁:Times New Roman / Calibri。
   - 中文 / 日文:思源宋体 / 思源黑体(Source Han)。
   - 阿拉伯语:Noto Naskh Arabic;希伯来语:Noto Sans Hebrew。
2. 行距按最「高」的脚本定,别用拉丁行距裁掉阿语/天城文/泰文的上下标记。
3. RTL 段落对齐用「起始/两端」对齐,别写死 left。

## 自查清单(排版也要过一遍再交付)

1. 标题层级统一吗?
2. 段落是不是短?缩进/对齐用的是这套文字系统的规则吗(中文缩进两字 + 两端对齐、拉丁空行不缩进)?
3. 标点、引号跟这句话的语言一致吗?
4. RTL(阿语/希伯来语)段落方向对吗?数字嵌入方向对吗?
5. 一句话内混了两种文字系统的标点吗?
6. 中英/数字之间该加的空白加了吗?
7. 书名/作品名用的是该语言的习惯(斜体/书名号)吗?
