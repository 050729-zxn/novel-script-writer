# 文风蒸馏 · 喂文·学文风

用户给几篇自己的文字（或指定某作者/某作品），提炼「怎么写」的指纹，之后照这份指纹写 / 改 / 校。来源已蒸馏自 wjs-distilling-style（9 轴指纹 + 锚点原句）、perfectly-replicate-writing-skills（7+1 维 + 3 次成信号）、fiction-distiller（小说专用全维蒸馏）。

## 一、总原则（先记这 5 条，比 9 轴更重要）

1. **文风是指纹，不是形容词。** 能照着复现、别人读完说「像」，才算蒸馏出来。「文笔细腻」「节奏快」这种形容词没用，要落到可执行：平均句长多少、短句占几成、形容词密度多少、怎么起头怎么收尾。
2. **规则会骗人，锚点原句不会。** 每个轴除了写「观察 + 可执行规则」，还必须从样本摘 2–3 句真实原句当锚点。没有锚点的轴等于没蒸馏——改写时规则会空转，原句能把你拉回那个味儿。
3. **3 次成信号。** 同一个特征在 ≥2 处（最好 ≥3 处、不同篇）出现才算风格信号；只出现一次是即兴，不是签名。
4. **保留矛盾与瑕疵。** 作者写得不一致的地方别抹平，怪癖、生硬处、口头禅、不工整的句式是身份标记。用户说「有点生硬」的那部分，往往正是他本人的指纹。
5. **调料不是公式。** 签名动作（单句成段 / 自造词 / 破折号 / 短句砸下来）是工具不是清单。短场景就短写，别把每一样都堆满——堆满就是拙劣模仿，不是那个人。

再三条纪律：
- **只抓「怎么写」，不写「什么立场」**：他爱写逆袭、三观如何，是内容不是文风；指纹只问「同一个桥段换了他来写会长什么样」。
- **量化 > 印象**：「平均句长 12 字、三成句子不足 8 字」有用；「喜欢短句」没用。
- **负面定义边界**：他**绝不**写什么（某个句式、某类词、某种视角、某类桥段），往往比正面特征更能定义风格。

## 二、九轴指纹（小说专用）

每轴三件事：**观察**（样本里看到什么，尽量量化）、**可执行规则**（写/改时怎么照做）、**锚点原句**（2–3 句真实原句，照抄不改）。

| # | 轴 | 抓什么 |
|---|---|---|
| 1 | 句与标点 | 平均句长、长短交替的拍子、标点签名（破折号/省略号/句号密度/感叹/问句）、一句成段 |
| 2 | 段落 | 平均段长、单句成段密度、长段密度、对话怎么分段 |
| 3 | 词汇 | 高频词、口头禅、自造词、雅俗倾向、方言/文言/现代网络语、人名称呼习惯 |
| 4 | 对话 | 对话占比、怎么说话（打断/停顿/称呼/语气词/口头禅）、引号用法、对话与动作的搭配 |
| 5 | 视角与距离 | 第几人称、心理描写深浅、全知还是限制视角、镜头远近（贴脸特写 vs 远景白描）、是否进角色内心 |
| 6 | 意象与比喻 | 家常 vs 抽象、比喻频率、感官侧重（视觉/听觉/触觉/嗅觉）、陈词意象还是新意象 |
| 7 | 情绪强度 | 克制 vs 喷发、白描 vs 抒情、内心戏多寡、情绪温度（冷/温/烫） |
| 8 | 节奏与结构 | 开头怎么起（场景/断言/动作/对白）、章节怎么收（钩子/留白/点题）、推进快慢、伏笔密度 |
| 9 | 雷区 | 他绝不写的东西：某句式、某类词、某桥段、某视角跳法 |

## 三、蒸馏流程（喂文 → 成卡）

1. **收样**：样本入库。小说建议 **2–3 章起步**（每章 ≥2000 字），理想 3–5 章且覆盖不同场景（打斗 / 对话 / 心理 / 景物）。**不足要明确提示用户**：指纹会不稳，容易把一章的偶然写法当签名。
2. **逐轴拆解**：按上表 9 轴逐轴分析，**每轴摘锚点原句**（照抄，别改）。
3. **成卡**：写成下面模板，让用户过目 / 手改。卡是「真源」，后面写作、改写、校对都拿它当手感基准。**存到 skill 目录 `style-cards/<作者名>.md`**,之后说「用 XX 味儿写」就直接调对应卡,不用重新蒸馏。
4. **多作者 / 多类型**：如果样本是不同作者或不同类型（玄幻正文 + 都市短文），分开各建一张卡，别混着蒸馏。

### 成卡模板

```markdown
# 文风卡：<作者名 / 作品名>
样本：N 章，约 X 字（不足 3 章须标注「指纹不稳」）

## 一、句与标点
观察：…（量化）
规则：…
锚点：> 原句一 / 原句二

## 二、段落
…（九轴各一段，每轴：观察 / 规则 / 锚点）

## 九、雷区（绝不写）
1. …
2. …

## 应用纪律
- 签名动作是工具不是清单，短场景短写，不堆满。
- 只换「怎么写」，不换「写了什么」；别为凑风格编造原文没有的事实/桥段。
```

## 四、应用（拿卡去写 / 改 / 校）

分两档，默认走轻档：

- **轻档（日常写作与校对）**：动笔前扫一眼卡的「九轴规则 + 雷区 + 锚点句」建立手感；第三步校对时，把「像不像这个文风」加进第 4 步读者视角通读——专抓「哪句不像他写的、哪个词他绝不会用、哪处节奏跑味了」，出戏处按卡改回。不用每写一段就重读全文。
- **重档（专门喂文 / 学文风改写已有文本）**：先抽**事实骨架**（把原文的情节/信息/结论列成几条 bullet，这是「保内容」的锚），再按 9 轴改写——可调开头收尾、节奏、段落、措辞，**事实骨架不增不减**，只换说法不换事实；写完对照骨架查一遍有没有篡改/丢失/新增。宁可某轴只做到 4 分，也不为凑风格编一段原文没有的情节。

## 五、红旗（出现就回正轨）

- 「列几条特点就开始写」→ 没摘锚点、没填 9 轴 = 没蒸馏。
- 「这段我读着挺像，不用再核了」→ 自评不算数，对照锚点原句核。
- 「原文这句不够味儿，我补一句」→ 停，事实骨架不增不减，加料是改内容不是改风格。
- 「把他所有签名动作全用上更像」→ 堆满是拙劣模仿，看总原则第 5 条。
- 「样本一章就够」→ 提示指纹会不稳。
- 「把观点/三观写进卡里」→ 那是内容不是文风，删。

## 六、常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 指纹只有抽象规则、没锚点原句 | 改写时空转，套不出味儿 | 每轴强制摘 2–3 句真实原句 |
| 把内容立场当文风 | 改写跑偏成换观点 | 指纹只问「怎么写」 |
| 形容词描述（细腻/快/爽） | 无法照着执行 | 换成可量化观察 + 可执行规则 |
| 单次出现就当签名 | 把即兴当风格 | 3 次成信号 |
| 抹平矛盾与瑕疵 | 把「他」改没了 | 保留怪癖，那是身份标记 |
| 改写顺手加料删料 | 原意被改 | 先抽事实骨架，改写不增不减 |
| 签名动作堆满 | 拙劣模仿 | 短场景短写 |
