# 镜头提示词:通用结构化格式

每个镜头都附一段提示词,供任何主流 text-to-video 工具(可灵、即梦、Sora、Runway、Pika、Vidu、海螺等)直接使用。按下面字段逐项写清,再拼成一段话;字段可缺,但**景别、运镜、主体动作、环境、氛围**这五项尽量齐全。

## 字段表

| 字段 | 内容 | 示例 |
|------|------|------|
| 景别 | 大远景/远景/全景/中景/中近景/近景/特写/大特写 | 特写、中景 |
| 运镜 | 固定/推/拉/摇/移/跟/环绕/升降/手持/甩 | 缓慢推近 |
| 环境 | 地点、时间、天气、背景元素 | 深夜的城中村巷口,雨刚停 |
| 主体与动作 | 谁、穿什么、做什么(具体、连续) | 一个穿旧灰夹克的男人蹲在路边,慢慢抽一根烟 |
| 表情/情绪 | 面部与情绪状态 | 眉头微皱,眼神放空 |
| 光线/色调 | 光源、明暗、色彩倾向 | 冷青色的路灯光,高对比剪影 |
| 氛围/风格 | 情绪基调、画面风格 | 压抑、写实、电影质感 |
| 时长 | 镜头大约持续 | 约 4 秒 |

## 拼装模板

`【景别】<...>,【运镜】<...>。【环境】<...>。【主体】<...>,【动作】<...>。【表情】<...>。【光线/色调】<...>。【氛围/风格】<...>,写实电影质感,约 <N> 秒。`

提示词用一句话写完,别分行;描述要具体到「能直接照着画」,不要抽象形容词(如「气氛压抑」要落到「冷青光、雨滴、无人街道」)。

## 完整示例

**镜头 3**
- 场景:雨夜,城中村巷口
- 画面:男人蹲在路边抽烟,远处一辆车开过,车灯扫过他半张脸。
- 台词:无
- 提示词:
`中近景,缓慢推近。深夜城中村巷口,雨后路面反光。一个穿旧灰夹克的男人蹲在路边,慢慢把烟送到嘴边,烟头明灭。眉头微皱,眼神放空。冷青色的路灯从头顶打下,脸一半在光里一半在阴影里,背景有车灯扫过。压抑、写实、电影质感,约 4 秒。`

**镜头 7**
- 场景:办公室,白天
- 画面:女主把辞职信拍在老板桌上,转身就走。
- 台词:"我不干了。"
- 提示词:
`中景,固定机位。明亮现代办公室,落地窗透进自然光。一个穿浅色衬衫的年轻女人把一张纸用力拍在办公桌上,抓起包转身大步走向门口,老板坐在桌后愣住。表情坚定,下巴微抬。正面柔光,整体清冷偏白。干脆利落、都市剧质感,约 5 秒。`
